# START HERE — Omytea-Almighty organization contract

Read [`ORG-SYNC.md`](ORG-SYNC.md) before editing, committing, or publishing.
The only canonical GitHub repository is
`https://github.com/Omytea-Almighty/omytea-protocol.git` (SSH form is also allowed).

A normal reviewed commit may be queued for safe automatic push. Never automate
`git add` or commit creation; never pull, merge, rebase, force-push, delete refs,
change visibility, bypass hooks, or cross a curated-public release gate. If the
identity, visibility, origin, ancestry, content scan, receipt, or remote-SHA gate
fails, preserve the local commit and report `BLOCKED_*`.

Members may create and upload to repositories they own. Modifying, deleting,
transferring, archiving, or changing visibility of another owner's repository
requires explicit authorization.
